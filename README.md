# 📦 Divs Interativas
Este projeto cria uma interface interativa com quatro **divs** empilhadas. 
Ao clicar em qualquer uma das **divs**, elas trocam de posição com outra **div** de acordo com a sua ordem e camada (z-index). 
É uma forma divertida de visualizar e interagir com elementos posicionados de forma absoluta!

# 🚀 Funcionalidades
- **Troca de Posição**: Quando uma **div** é clicada, ela troca de posição com outra **div** de acordo com o índice.
- **Z-index**: O índice de empilhamento das **divs** também é alterado, criando um efeito visual interessante.
- **Transições Animadas**: As **divs** se movem suavemente de um lugar para outro com animações de transição.
